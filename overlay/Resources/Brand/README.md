# Halo logo assets

The symbol is a seven-dot H with an open dotted halo. The wordmark uses Archivo Black converted into vector paths with adjusted spacing. The source font and OFL license are included. The mark is newly drawn; the user's reference logos were used for visual direction.

SVG files are the vector masters; transparent PNGs are convenience exports. Use Imperial on Night and Night on Chalk. White artwork is for dark backgrounds. App-icon masters are 1024 square. The small menu template omits the outer halo for legibility and should be rendered as a macOS template image.

Keep at least one large-dot diameter of clear space around the full mark. Use the full mark at 32 pt or larger; below that use the simplified menu template. Do not stretch, add gradients, or replace the live orb with the logo. Check final icon masking in the actual app bundle.
